# 팀 게시판용 구조도

최종 결과보고서(2026-10-06)와 발표자료에서 옮겨 그린 그림입니다. `.excalidraw` 파일을 https://excalidraw.com 에서 열면(메뉴 → 열기) 그대로 고칠 수 있습니다.

| 파일 | 내용 |
|---|---|
| `b1_구조도` | 프로젝트 한눈에 보기: 문제 → 데이터 → 방법 → 결과 → 활용 → 검증 |
| `b2_결과지도` | 경로 여섯 고리 중 확인한 것, 6개 지표 판정 |
| `b3_매칭모델` | 상품 매칭 모델: 언제 · 누구에게 · 누구부터 · 무엇을 |
| `b4_파일럿` | 효과 검증 파일럿: 층화 무작위 1:1 비교 설계 |

모든 수치는 교육용 법인 익명데이터의 집계값이며 법인 단위 값은 없습니다.
